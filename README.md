Project Overview

This project implements and compares numerical methods for solving nonlinear equations of the form  f(x)=0.
The project focuses on the Bisection Method and Newton's Method, including convergence analysis, error tracking, and performance comparison.

Objectives:
Implement numerical methods for finding approximate roots.
Apply stopping criteria based on tolerance and iteration limits.
Record iteration history, residuals, and step sizes.
Compare the convergence and performance of the methods.
Visualize and analyze numerical results.




Methods:
1. Bisection Method
Implemented by Member 1. This method finds a root by repeatedly halving an interval that brackets a root.

2. Newton's Method
Implemented by Member 2. This method uses function values and derivatives to iteratively approximate a root.

3. Shared Diagnostics
Implemented by Member 3. This module provides input validation, residual calculations, stopping criteria, and iteration-history records.

4. Experiments and Visualization
Implemented by Member 4. This component compares the methods, studies tolerance effects, and generates plots.


Project Status
Work in progress. Implementation, testing, experiments, and documentation will be updated as development proceeds.
